# קטלוג KIKO – איך מעדכנים

הקטלוג שמופיע בשאלון (`pre-use.html`) נטען מהתיקייה הזו. כל שינוי שנשמר כאן ב־GitHub מופיע באתר תוך דקה–שתיים, בלי לגעת בקוד השאלון.

```
catalog/
  catalog.json      ← שמות, תיאורים, משפחות ותגיות ההתאמה
  images/<id>.webp  ← תמונה אחת לכל חלק
```

## להחליף תמונה של חלק
1. פותחים את `catalog/images` ב־GitHub ← **Add file ← Upload files**.
2. מעלים תמונה **באותו שם בדיוק** (למשל `spikes_high.webp`). היא תחליף את הישנה.
3. אם התמונה בפורמט אחר (`.jpg` / `.png`), מעלים אותה ומעדכנים את השדה `img` של החלק ב־`catalog.json` (למשל `"img": "images/spikes_high.jpg"`).

מומלץ: תמונה ריבועית, 800–1200 פיקסלים.

## לשנות שם / תיאור / תג
עורכים את `catalog.json` ב־GitHub (סמל העיפרון ✏️) ← **Commit changes**.

## להסתיר חלק או משפחה בלי למחוק
מוסיפים לחלק (או למשפחה) את השורה `"hidden": true`. כדי להחזיר: מוחקים אותה.

## להוסיף חלק חדש
מעתיקים בלוק של חלק קיים מאותה משפחה, ומשנים:
- `id` – מזהה ייחודי באנגלית בלי רווחים (גם שם קובץ התמונה)
- `name`, `badge`, `img`
- `match` / `avoid` / `actions` / `sensory` / `intensity` – התגיות שלפיהן השאלון ממליץ על החלק. הכי פשוט להעתיק מחלק דומה.

## אחרי כל עדכון
- משנים את `"version"` בראש הקובץ (למשל `2026-10-18-2`). כך דפדפנים יטענו את התמונות החדשות מיד ולא מהזיכרון.
- שימו לב לפסיקים ולמירכאות: קובץ JSON שבור ימנע את טעינת הקטלוג. אפשר לבדוק ב־https://jsonlint.com לפני שמירה.
